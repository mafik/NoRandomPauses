# No Random Pauses in Beat Saber

This is a mod for Beat Saber that prevents the game from randomly pausing while a song is playing.

Some headsets (for example Steam Frame) have an issue where the presence detector randomly fails every now and then. This mod suppresses these one-off failures.

## Installation

Download the .dll from the releases page & put it in the BeatSaber's `Plugins/` directory. The mod should be loaded automatically on the next startup.
